> **状态**：仅记录想法与源码调研，未排期、未批准、未实现；标注〔已选定〕的卡片只代表下一批
> 范围意向，实施前仍需建立正式 milestone/ADR
> **使用方式**：未来从下列需求卡中选择范围，再建立正式 milestone/ADR；本文件本身不是实施计划
> 2026-10-14 扩池：在导入需求卡（APO-01～10）之外，收录非导入类对齐候选（APO-11 起）与周边便利项

## 1. 背景

EqualizerAU 当前只运行一份 schema v9 原生配置（M12 起含滤波器节点），没有 EqualizerAPO
parser、Include resolver、导入预览或外部配置监听。未来可以把 EqualizerAPO 文本作为一次性导入
来源，但原生 JSON 应继续作为唯一可写事实来源，导入后仍需显式 Save。

2026-07-27 已读取本地 EqualizerAPO 的 `FilterEngine.cpp` 和 Preamp、Channel、GraphicEQ、
Convolution、Include factories，确认：

- 每行按第一个 `:` 分割；参考实现会静默忽略未知命令和多数解析失败；
- `Preamp` 接受逗号小数并用宽松 `swscanf` 解析；
- `Channel` 以空格拆分并大写，作用域影响后续效果；
- `GraphicEQ` 宽松提取数字对、丢弃孤立尾值并排序；
- Include 与 Convolution 相对路径以声明命令的文件目录为基准；
- Include 继承调用点 Channel，返回后恢复调用前 Channel；
- 参考 Include 只有 100 层深度限制，没有明确环诊断；
- 参考 Convolution 支持的格式多于 EqualizerAU 当前严格 WAV 契约。

这些是兼容事实，不代表应该复制其静默失败行为。

2026-10-14 完成一次全量功能对比（本地参考源码逐项核对），补充事实：

- 命令注册表全集：`Filter`（BiQuad 八类、14 个别名）、`Preamp`、`GraphicEQ`、`Convolution`、
  `Delay`、`Copy`、`Channel`、`Device`、`Eval`、`If`/`ElseIf`/`Else`/`EndIf`、`Include`、
  `Stage`、`VSTPlugin`、`LoudnessCorrection`。EqualizerAU 已有原生承载：Preamp、GraphicEQ、
  Convolution、Channels、八类经典滤波器（ADR-0021）；
- Editor 侧每个命令均有专属 GUI；分析面板由 `AnalysisThread`（fftw 实时 FFT）驱动，包含
  实时频谱、整链峰值增益读数（超阈值红色警示）与延迟读数；
- Editor 支持多份配置文件（config profile）切换与 `FilterTemplate` 参数模板（名称 +
  配置行 + 存放路径，可保存复用）；
- `Delay` 为单值命令：`Delay: <数值> ms|samples`（小数可用、单位不区分大小写），受前置
  Channel 作用域约束；
- `LoudnessCorrection` 是音量自适应滤镜：`VolumeController` 跟踪系统音量，后台线程按音量
  重算低/高搁架参数与 preAmp，不是固定曲线。

## 2. 可独立选择的需求卡

### APO-01：单文件解析与逐行诊断

解析空行、`#` 注释、Preamp、Channel 和 GraphicEQ；每个结果保留文件、行号和原文。未知命令、
尾随垃圾、非有限值、重复频率或超产品契约内容明确阻断，不静默忽略。无文件写入和 UI 依赖。

### APO-02：导入预览

选择根配置后展示规范化节点顺序、来源和全部 warning/error。存在阻断项时禁止确认，不提供
“忽略后继续”。取消预览不得修改草稿、sidecar 或音频状态。依赖 APO-01。

### APO-03：Preamp 与 GraphicEQ 草稿导入

把合法 Preamp 和 GraphicEQ 转为原生节点；GraphicEQ 域外正频率点按 M6 契约原样保存但不参与
20 Hz...20 kHz DSP。确认形成一个未保存草稿步骤，Undo 可完整恢复，仍需 Save。依赖 APO-01/02。

> 2026-09 已交付更小的剪贴板切片：⌘V 直接粘贴 EqualizerAPO `GraphicEQ:` 文本创建图形 EQ 节点
> （无 Preamp、无文件解析、无预览）。该切片的导入归一化丢弃域外频点并夹紧增益，是用户确认
> 的决策，见 PRD 7.2 与 architecture.md。本卡的文件导入路径仍未排期；域外点"原样保存"的取舍
> 是否延续到文件导入需在实施前重新确认。
>
> 2026-10 起经典 `Filter:` 指令族已有原生节点承载（ADR-0021），⌘V 文本回退同样解析 `Filter:`
> 行。本卡实施时，Filter 行应映射到原生滤波器节点而非重新引入解析产物；`IIR`、`Delay`、
> `Copy`、`LoudnessCorrection`、`VSTPlugin` 仍无对应节点，文件导入需为它们定义显式拒绝诊断。
>
> 2026-10-14：`Delay` 与 `LoudnessCorrection` 已选定为下一批原生节点（见 APO-11/12），实施后
> 本条的显式拒绝名单相应缩短为 `IIR`、`Copy`、`VSTPlugin`。

### APO-04：Channel 作用域导入

把 `Channel: all`、正整数和非空标识转换为 Channels 节点，保留命令顺序和后续作用域；不根据
当前设备声道数猜测或删除未解析标识。依赖 APO-01/02。

### APO-05：嵌套 Include 配置树

递归解析多文件：子文件继承调用点 Channel，返回后恢复外层 Channel；必要时生成恢复 Channels
节点。相对 Include/Convolution 路径以当前文件目录解析。使用当前递归栈检测环，允许同一文件在
退出调用栈后再次 Include。正式实施前需冻结深度、文件数和聚合字节预算。依赖 APO-01/04。

### APO-06：Convolution 无副作用检查

在预览阶段读取并验证 WAV 大小、格式、时长、采样率、声道和样本，但不写应用 IR 目录；不支持
的 FLAC/OGG 等格式明确报告。依赖现有 M1 WAV 契约，可独立于最终导入事务实施。

### APO-07：Convolution sidecar 批量事务

为所有 WAV 预分配 storage IDs，整批写入；任一写入或后续草稿替换失败时，只回滚本事务创建的
资源。当前 `importWAV` 是先持久化再新增节点且没有批量回滚，不能直接循环复用。需先建立 ADR、
失败恢复和 orphan 清理证据。依赖 APO-06。

### APO-08：整份配置原子替换

确认后默认替换当前节点草稿、保留 effectsEnabled，并形成一个 Undo step；active/saved chain 在
显式 Save 前不变。解析、容量、IR 或草稿失败时原草稿保持不变。依赖所选 parser 和资源需求。

### APO-09：EqualizerAPO 文本导出

把受支持节点导出为新的 APO 文本文件。它不改变运行配置，也不建立反向同步。需要先单独定义
Channels、域外 GraphicEQ 点、IR 文件复制和不支持节点的导出契约，不与导入默认捆绑。

### APO-10：外部文件持续链接与监听

让运行配置持续依赖 Include 文件并在文件变化时自动更新。该模式会绕过显式 Save、Undo/Redo、
generation 和单一事实来源，当前明确不建议。若未来确有需求，必须作为独立产品模型重新论证，
不能视为 APO-05 的自然延伸。

**非导入类候选（2026-10-14 增补，APO-11 起）**

### APO-11：Delay 延迟节点 〔已选定：2026-10-14〕

参考语法 `Delay: <数值> ms|samples`，单值、小数可用、单位不区分大小写，受前置 Channel 作用域
约束。原生化为节点需冻结契约：最大延迟上限（按采样率折算缓冲预算）、ms/samples 双单位语义、
与 Channels 节点的组合规则；实时实现为预分配延迟缓冲，回调内只做有界复制。需 ADR 与全层测试。

> 2026-10-14 评估：参考实现把 ms 值四舍五入到整数采样，无分数延迟；原生实现建议整数 + 分数
> 两级（分数部分线性插值，每样本一次乘加），延迟值在链发布时冻结，回调内不变化。

### APO-12：响度校正节点 〔已选定：2026-10-14〕

> 2026-10-14 用户裁决：效果优先，**首版即交付动态模型**——音量跟踪是准入条件，静态曲线只
> 是动态模型的基础构件（同一套曲线计算代码），不单独作为交付物。此前"先交付静态版"的建议
> 已否决：不跟音量的响度补偿效果不如参考实现，没有意义。

macOS 动态模型：控制层监听输出设备音量（AudioObject 属性监听，实时面零新增），按 1 dB 一档
防抖；音量变化后后台重算等响曲线差并重编译最小相位 FIR，经既有原子发布机制换链（GraphicEQ
曲线拖动已证明交互级重编译可行）。用户设定参考音量做校准（旋钮位置≠真实响度，此项与参考
实现相同，无法靠算法消除）。防削波 preamp 策略与 FIR 延迟取舍由 ADR 裁决。

> 2026-10-14 评估（不必复制参考实现）：
>
> - 参考算法事实：两个固定搁架（75 Hz/Q0.52、10 kHz/Q0.9）+ 手调系数按音量差线性外推，
>   并在音频线程用临界区换系数——前者是等响曲线的两搁架粗近似，后者违反本项目实时铁律。
> - 业界对照：LSP Loudness Compensator（FFT 多段、按精确 ISO 226 等响曲线差逐段增益，
>   已更新 2023 版数据；ISO 226:2023 与 2003 版差异 ≤0.6 dB，数据版本不是关键差异）；
>   CyanogenMod DSPManager 为信号能量驱动的自适应低频（类压缩器动态，目标不同，不采纳）。
> - 倾向方案：「等响曲线差 + 复用 GraphicEQ 最小相位 FIR 编译管线」——精确曲线、零新 DSP
>   拓扑、静态版体量小；动态版直接复用 ADR-0003 原子发布（已有万次发布竞态测试证据）。
> - 备选低延迟方案：离线曲线拟合 N 个级联双二阶（零延迟，但需新增拟合代码）。FIR 延迟
>   vs 拟合复杂度、音量观测与量化步进（如 1 dB 一档）、防削波 preamp 策略由 ADR 裁决。

### APO-13：全链路静态响应曲线与峰值增益警示

参考分析面板的静态部分：整链合成响应曲线（幅频）+ 峰值增益读数，超标红色警示。纯控制层
数学计算，不触碰实时线程；需为双二阶、GraphicEQ FIR 与卷积 IR 建立统一频响模型。峰值增益可
联动 Preamp 给出防削波建议。

### APO-14：实时频谱仪

参考 `AnalysisThread`：对正在播放的音频做 FFT 频谱显示。必须在实时回调内只做预分配缓冲抄录
与原子发布，UI 侧消费快照；需独立实时安全 ADR 并通过实时安全审计。展示层可复用 APO-13，
建议 APO-13 交付后再评估。

### APO-15：Copy/Sum/Multiply 声道路由

参考是显式声道接线模型（Copy GUI 画连线），与本项目 Channels 范围模型差异大，引入前需产品级
论证是否双模型并存。暂不推荐。

### APO-16：原始 BiQuad 系数节点（IIR）

参考允许直接输入双二阶系数定义滤波器。专家向小卡，可与 APO-11 同方式原生化。优先级低。

### APO-17：多套配置 profile

参考 Editor 支持多份配置文件（config profile）切换。涉及单一配置事实来源与配置管理模型，需
产品决策后细化；与 PRD §12「配置导入范围」属不同议题。

### APO-18：登录时启动

对应 PRD §12 待确认事项「是否需要登录启动」。macOS 用 LoginItem（SMAppService）实现，纯
应用层、无实时面；落地前先在 PRD 关闭该待确认项。属周边便利项而非参考对齐。

### APO-19：滤波器参数模板

参考 `FilterTemplate`：把调好的配置行存为命名模板复用。对应原生「节点参数预设」，价值低、
体量小，按需排期。

## 3. 推荐选择顺序

2026-10-14 已选定下一批范围：APO-11 Delay + APO-12 响度校正（动态模型为首版准入条件：
音量跟踪 + 等响曲线差曲线），实施前需建立 ADR 与各层测试。

导入主线（维持原推荐顺序）：

1. APO-01 + APO-02：先得到无副作用 parser 和预览；
2. APO-03 + APO-04 + APO-08：交付单文件基础导入；
3. APO-05：增加 EqualizerAPO 原生多文件 Include 语义；
4. APO-06 + APO-07：具备回滚后再导入 Convolution；
5. APO-09 或 APO-10 仅在出现独立用户需求时重新评估。

对齐支线（按价值与体量排序）：

1. APO-13 静态响应曲线与峰值增益警示：纯控制层，无实时风险；
2. APO-14 实时频谱仪：依赖 APO-13 展示层，需独立实时安全 ADR；
3. APO-16 原始系数节点、APO-18 登录启动、APO-19 参数模板：小卡，按需；
4. APO-15 声道路由、APO-17 多配置 profile：需产品级论证后再排期。

## 4. 不变约束

- schema v9 原生配置是唯一运行和持久化事实来源；
- EqualizerAPO 文件默认只是导入来源，修改后不会自动同步；
- 导入预览不写配置或 sidecar，不启动或重配音频；
- 不支持或损坏内容必须可定位，不复制参考实现的静默丢弃；
- 非导入类候选（APO-11 起）同样受实时回调约束：预分配、原子发布、无锁无分配；
- 所有确认操作仍遵循草稿、Undo/Redo、显式 Save、4 MiB 配置预算和实时线程隔离。
