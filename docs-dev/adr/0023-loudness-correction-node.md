# ADR-0023：响度校正节点（动态、等响曲线差）

- 状态：Accepted
- 日期：2026-10-14
- 范围：处理链节点模型、等响曲线编译、输出音量观察与自动重发布
- 关联：ADR-0003、ADR-0004、ADR-0005、ADR-0007、ADR-0008、ADR-0013、ADR-0020
- 用户已确认范围（2026-10-14）：首版即交付**动态模型**，音量跟踪是准入条件，效果不劣于
  EqualizerAPO 参考实现；采用等响曲线差 + FIR 编译路线，不复制参考实现的两搁架近似

## 背景

人耳等响特性（ISO 226 等响曲线）：音量越低，低频与高频所需能量相对中频越多；小音量听音
会显得单薄发闷。响度校正 = 音量低于参考值时按等响曲线差补偿频率平衡，音量回到参考值时
补偿归零。

EqualizerAPO 参考实现（`filters/loudnessCorrection/`）用两个固定搁架（75 Hz/Q0.52、
10 kHz/Q0.9）+ 手调系数按音量差线性外推近似曲线差，并在音频线程用临界区换系数。LSP Loudness
Compensator 采用精确 ISO 226 曲线差、FFT 多段实现。本项目 GraphicEQ 已具备"dB 曲线 →
最小相位 FIR（倒谱法、长度随采样率缩放，ADR-0020）"的控制层编译管线，且 Runtime 发布
协议自带 10 ms 交叉淡化与候选合并（ADR-0003）；响度曲线只是另一条 dB 曲线。

## 决策

1. **节点模型**：新增 `loudness` 节点，负载为 `M1LoudnessSpecification`：
   `referenceVolumeDB`（输出音量旋钮域，音量处于该值时补偿为零）与 `strength`
   （0…1，默认 1）。**当前音量不落盘**，属运行时环境。
2. **补偿曲线**：采用 ISO 226:2003 解析拟合（Suzuki–Takeshima 2004）的等响曲线差：
   `gain(f) = strength · [L_p(f, P_ref) − L_p(f, P_ref + (V_cur − V_ref))]`，定义域
   20 Hz…20 kHz，整体夹紧 ±24 dB 后整体下移 `max(0, 曲线最大增益)` dB（防削波防护，等效
   参考实现的防护性 preamp）。参考听音级假设 `P_ref = 85 phon`（文档化假设；strength
   吸收个体差异）。`V_cur == V_ref` 时曲线平坦，不产生阶段（复用 FIR 编译器平坦捷径，
   零成本零延迟）。
3. **编译复用**：把 GraphicEQ FIR 编译入口从"控制点插值"泛化为"目标增益函数"，响度与
   GraphicEQ 共用同一倒谱最小相位实现、同一长度缩放合同（ADR-0020）；Runtime 零改动。
4. **音量观察**：控制层对当前输出设备挂 `AudioObjectAddPropertyListener`
   （`kAudioDevicePropertyVolumeScalar`，主声道），经
   `kAudioDevicePropertyVolumeScalarToDecibels` 转 dB；1 dB 一档量化 + 300 ms 防抖。监听器
   生命周期绑定路由（运行中挂载，停止/换路由时卸载）。实时线程零接触。
5. **自动重发布**：防抖后的音量变化触发从**已保存配置**（非草稿）重建预编译链并走既有
   prepare/publish 路径；Runtime 交叉淡化保证无爆音，切换中的重复发布自动合并。配置
   generation 不变（无持久化、无 Undo 步、不触碰草稿）。持久化操作进行中则推迟合并；
   音频停止时只更新记忆值供下次启动使用。
6. **降级路径**：设备不支持标量→分贝转换时用 `20·log10(scalar)` 近似（文档化偏差）；音量
   属性不可观察时曲线冻结在参考值（无补偿）并产生可见诊断。
7. **schema v10**：与延迟节点共用本次升版（ADR-0022）；v9 及更早配置无损加载。
8. **UI**：节点行含参考音量（dB）与强度（%）两个参数字段，中英文案；本期不做曲线渲染
   （属 APO-13 响应曲线需求卡）。

## 后果

- 小音量听音时低频/高频按精确等响曲线差自动补偿，音量变化时曲线平滑跟随（无爆音、无堆积）；
  曲线精度与跟随体验均优于参考实现的两搁架近似。
- 新增"环境驱动自动重发布"路径：扩展 ADR-0003 发布协议的使用方式，不改变草稿/Save/Undo
  语义；generation 与持久化事实来源不变。
- 旋钮位置≠真实听音响度的先天局限由参考音量校准项承担（参考实现同样存在）；信号驱动式
  自适应（类压缩器动态）、绝对声压级校准 UI、ISO 226:2023 数据替换（与 2003 版差异
  ≤0.6 dB）均不在本期。
